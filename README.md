# DL_exploration
A dedicated deep learning exploration repository using the Fruits 360 dataset.
---
## Dataset: Fruits 360

**Fruits 360** is a publicly available image dataset containing **120 types of fruits** with high-quality RGB images.  

### Key Details:
- **Number of Classes:** ~120 fruit types  
- **Image Size:** Original images are 100×100 RGB (can be resized for experiments)  
- **Training Images:** ~50,000  
- **Testing Images:** ~20,000  
- **Source:** [Kaggle Fruits 360](https://www.kaggle.com/datasets/moltean/fruits)

The dataset is ideal for **deep learning experiments** because:
- Images are high-quality and real-world, not synthetic
- It supports **multi-class classification**
- Large enough to apply **MLP, CNN, and transfer learning**
- Provides opportunity for **data augmentation, regularization, and ensemble methods**
- Great for **optimizer comparison** and studying model generalization
